§ 2   Method

The student acts.
The teacher steers.

Online distillation combines ordinary student trajectories with verified corrections, preserving the student's role as the agent executing each action.

01 / ROLLOUT

Discover the failure

The quantized student interacts with the environment. Its own observations and actions expose where decisions break down.

02 / CORRECTION

Guide a student retry

A frozen unquantized teacher supplies textual guidance. Restore the failure anchor, let the student retry, and verify the outcome.

03 / DISTILLATION

Learn from verified actions

Ordinary rows use reverse KL. Accepted corrections use forward KL against a frozen, steered quantized reference policy, with token-normalized full-vocabulary objectives.

Experimental configuration

Qwen3-VL-8B-Instruct; 4-bit weight quantization with 16-bit activations (AWQ / Marlin); frozen BF16 teacher. Independent demonstrations use checkpoint 8 in the ScaleWoB BestBuy environment.

Three repetitions per task demonstrate these specific executions. They do not establish generalization or aggregate improvement. Phone evidence · Code evidence
